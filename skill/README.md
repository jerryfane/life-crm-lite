# The life-crm lite skill

`SKILL.md` is the whole skill: paste it as a Project's instructions. Step by step with pictures: https://life-crm-lite.jerryfane.com

**Claude** (claude.ai): **Projects** > **+ New Project**, name it `life-crm` > **Set project instructions**, paste `SKILL.md`, **Save instructions**. Next to **Files**, click **+** and add [template.html](https://life-crm-lite.jerryfane.com/page/template.html) (the page). Then start a chat in the Project.

**ChatGPT** (chatgpt.com): **New project**, name it `life-crm`, memory **Default** > **•••** > **Project settings**, paste `SKILL.md` into the instructions, save. Plus and other paid plans: **Add files** > [template.html](https://life-crm-lite.jerryfane.com/page/template.html). Free: skip the file; you'll use the viewer page.

No Projects on your plan? Paste `SKILL.md` as the first message of a new chat.

Simulation: `python3 tools/simulate.py` (see the file's header).
